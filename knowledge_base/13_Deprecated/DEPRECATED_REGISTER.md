# Deprecated Register

Purpose: prevent AI from citing old or superseded workflows, scripts, templates, or SOPs.

## Rules
- Do not use deprecated content for customer replies unless the user explicitly asks for historical comparison.
- If a newer workflow JSON exists, use the newer JSON-derived SOP.
- If Notion Active FAQ conflicts with old SOP text, use the Active FAQ unless business rules say otherwise.

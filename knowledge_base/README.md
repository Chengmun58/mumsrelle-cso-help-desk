# Mumsrelle AI Knowledge Base

This folder is designed for Claude Project / ChatGPT Project upload.

## Folder Structure

- `00_AI_Instructions` — AI behavior and source priority
- `01_Company` — brand, contact, location, opening hours
- `02_Treatments` — treatment info and pricing references
- `03_Promotions` — active and historical promotion rules
- `04_SOP` — operational workflows
- `05_FAQ` — approved answers
- `06_Respondio` — workflows, broadcast, templates
- `07_Aoikumo` — POS and Aoikumo process
- `08_Sequoia` — Sequoia audit and migration references
- `09_Internal_Policies` — internal rules and exceptions
- `10_Templates` — WhatsApp, email, internal messages
- `11_Reports` — dashboard and reporting references
- `12_Troubleshooting` — common problems and fixes
- `13_Meeting_Notes` — meeting summaries and decisions

## Maintenance Rule
Every new SOP, FAQ, promotion, or policy should be added as a separate Markdown file and recorded in `CHANGELOG.md`.
